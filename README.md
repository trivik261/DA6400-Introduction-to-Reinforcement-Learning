# DA6400: Introduction to Reinforcement Learning

Course assignments and implementations organized by assignment number.

## Assignments

- **Assignment 1:** GridWorld value iteration and Acrobot SARSA/Q-learning (`assignment1/`)
- **Assignment 2:** MountainCar DQN experiments (`assignment2/Codes/`)
- **Assignment 3:** LunarLander, Reacher, Pendulum, and PEBBLE implementations (`assignment3/Implementation/`)

Each assignment has its own setup instructions and dependencies; see its README before running code. This source snapshot excludes generated plots, videos, model checkpoints, and course handouts.

## Interactive demo

Open [`web/gridworld/index.html`](web/gridworld/index.html) in a browser to explore the GridWorld assignment. The browser demo runs value iteration locally, lets you change the discount factor, and animates stochastic policy rollouts. It needs no backend or install step.
