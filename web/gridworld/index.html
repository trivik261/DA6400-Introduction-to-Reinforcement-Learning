Model details

5×5 grid; step cost −1; smoke adds −10; boulder crash −100; delivering water to the fire +100.

Moves are stochastic: normally 70% intended, 10% to either perpendicular cell, and 10% stay. At smoke cells, intended movement is 40%, perpendicular moves 10% each, and staying is 40%. Boundary moves leave the agent in place.

Value iteration uses the assignment’s transition and reward rules. Rollouts sample the same stochastic transitions, so repeated runs can take different paths.

How to use the policy explorer

1 · Choose the task phase

Use Water status to switch between empty-handed and carrying water. The displayed policy is recomputed for that phase.

2 · Set the discount factor

Move the γ slider, then select Recompute policy. Higher γ values give more weight to future rewards.

3 · Read the policy

Each arrow is the optimal action for that cell. The small number is its estimated state value under the current phase and γ. Lake, fire, smoke, and boulder cells are marked.

4 · Choose a starting cell

Click a grid cell. The gold outline marks the selected start; the inner highlight shows the agent’s current position.

5 · Try the rollout

Select Step once to advance one action, or Run to animate. Moves are stochastic, so repeated rollouts may take different paths.

6 · Start over

Select Reset to return to your chosen cell. Change γ or water status to compare policies.
